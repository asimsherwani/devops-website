Git practice kit

The commands used across a practical repository workflow, from setup to recovery.

Configure identity

git config --global user.name "Name"
git config --global user.email "email"

Set the author attached to your commits.

Start or copy

git init
git clone <repository-url>

Create a repository or bring down an existing one.

Inspect changes

git status
git diff
git log --oneline

See what changed and how the project evolved.

Stage and commit

git add .
git commit -m "message"

Prepare a snapshot and record it with a clear message.

Branches

git branch
git switch -c feature/name
git switch main

Explore work safely in focused branches.

Sync remote

git remote -v
git pull origin main
git push origin main

Connect, update, and publish the main branch.

Combine work

git merge feature/name
git rebase main

Bring a completed branch into the current line.

Recover cleanly

git restore .
git stash
git stash pop

Discard or temporarily shelve local changes.

Undo carefully

git revert <commit>
git reset --soft HEAD~1

Reverse a published change or revise the latest local commit.

Mark a release

git tag v1.0.0
git push origin v1.0.0

Label a stable point and publish the release marker.
